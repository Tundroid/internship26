TAsk 5 linux permissions

1. what does the chmod do?
answer:chmod changes the mode of a file or directory.it contro;s who can read, write or execute

2.what does chmod 755 mean?
answer: 755 means 

owner: rwx =7
group:r-x =5
others:r-x=5
the owner can read,write and execute while the group and others can only read and execute

3. what does chmod 600 do?
answer:600 means

owner: rw-
group:---
others:---
the owner can read, write but can not execute while while the group and others can not raed,write or execute the file

4. why does a script need execute permission?
answer:
A script needs execution permission to allow linux to execute directly

5. What security problem can occur when sensitive files have excessive permissions?
